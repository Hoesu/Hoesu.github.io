이 블로그 템플릿을 받은 사람을 위한 설명서. 처음 내 블로그로 바꾸는 법부터 글 쓰기, 꾸미기, 관리까지 순서대로 정리했다.

> 이 글은 `draft: true`라서 내 컴퓨터에서만 보이고 실제 사이트에는 올라가지 않는다. 같은 Template 카테고리의 **멀티미디어 표시 테스트** 글은 사진, 영상, 표, 수식, 코드가 실제로 어떻게 보이는지 확인하는 견본이다.

## 이 블로그로 할 수 있는 것

- **홈 화면이 스마트폰 홈 화면 모양**이다. 카테고리가 앱 아이콘으로 나오고, 누르면 앱이 열리듯 페이지가 커져 나온다. 아래에는 메뉴 독, 옆에는 글 쓴 기록(잔디), 최근 글, 랜덤 글 위젯이 있다
- 글은 **마크다운 파일 하나**로 쓴다. 폴더가 곧 카테고리다
- 사진, 움짤, 유튜브 영상, 코드, 수식, 표를 넣을 수 있다
- 목차, 검색, 태그, 댓글, 방문 통계, 관련 글 추천이 자동으로 붙는다
- 글을 저장하고 올리기만 하면 사이트에 자동으로 반영된다. 서버나 호스팅 비용은 없다 (GitHub Pages)

## 처음 한 번: 내 블로그로 만들기

### 1. 준비물

- [GitHub](https://github.com) 계정
- [Node.js](https://nodejs.org) (LTS 버전 설치)
- 글 쓸 편집기: [VS Code](https://code.visualstudio.com) 또는 [Cursor](https://cursor.com) 추천 (아래 `/` 명령어를 쓸 수 있음)

### 2. 저장소 만들기

1. 템플릿 저장소를 내 계정으로 가져온다 (Fork 또는 Use this template)
2. 저장소 이름을 **`내아이디.github.io`** 로 바꾼다. 그러면 블로그 주소가 `https://내아이디.github.io` 가 된다
3. 저장소 **Settings → Pages → Source** 를 **GitHub Actions** 로 바꾼다
4. 내 컴퓨터로 받아서(clone) 폴더를 편집기로 연다
5. 터미널에서 한 번만:

```bash
npm install
```

### 3. 내 정보로 바꾸기

아래 파일들에 있는 값을 내 것으로 바꾼다. 나머지는 건드릴 필요 없다.

| 파일 | 바꿀 것 |
|---|---|
| `astro.config.mjs` | `site:` 에 내 블로그 주소 |
| `public/robots.txt` | 맨 아래 주소를 내 블로그 주소로 |
| `src/consts.ts` | 블로그 이름(`SITE_TITLE`), 한 줄 소개(`SITE_DESCRIPTION`), GitHub 주소(`GITHUB_URL`), 메일 주소(`EMAIL`) |
| `src/pages/about.astro` | About 페이지 소개 글. 문단 하나가 `<p>...</p>` 하나 |
| `src/assets/wallpaper.jpg` | 홈 화면 배경화면 사진 ([아래](#배경화면)) |
| `public/favicon.svg` | 브라우저 탭에 뜨는 아이콘 |

`src/consts.ts`에는 댓글(`GISCUS`), 방문 통계(`GOATCOUNTER_CODE`), 검색엔진 확인(`SITE_VERIFICATION`) 값도 있다. 이건 전 주인의 값이라 **비우거나 내 값으로 바꿔야 한다**. 각각 [댓글](#댓글), [방문 통계](#방문-통계), [검색엔진 등록](#검색엔진-등록)에서 설명한다.

> 메일 주소(`EMAIL`)는 홈 화면 Gmail 앱에 들어가서 사이트에 공개된다. 공개하기 싫으면 `src/pages/index.astro`의 `links`에서 Gmail 줄을 지운다.

### 4. 기존 글 정리

`src/content/blog/` 안에 전 주인의 글이 들어 있다. 폴더째 지우면 된다. `template` 폴더(이 설명서와 견본 글)는 draft라 사이트에 안 올라가니 남겨둬도 된다.

## 매일 쓰는 흐름

1. **글 파일 만들기**: `src/content/blog/카테고리/글주소.md`
   - 예: `src/content/blog/diary/first-day.md` → `https://내주소/blog/diary/first-day/`
2. **글 정보 넣기**: 빈 파일에서 `/new` 를 치고 `Enter` → 제목, 태그를 채운다
3. **본문 쓰기**: 마크다운으로 쓴다 ([글 쓰기](#글-쓰기))
4. **미리 보기**: 터미널에서 `npm run dev` → 브라우저로 `http://localhost:4321`. 저장할 때마다 바로 반영된다
5. **올리기**:

```bash
git add .
git commit -m "새 글: 첫날"
git push
```

push 하면 1~2분 뒤 사이트에 반영된다. 바로 안 바뀌어 보이면 `Ctrl+Shift+R` 로 새로고침한다.

> 아직 쓰는 중인 글은 `draft: true` 로 두면 내 컴퓨터에서만 보이고 사이트에는 안 올라간다. 다 쓰면 `false` 로 바꿔서 올린다.

## 글 쓰기

### 글 정보

파일 맨 위 `---` 사이에 쓴다. `/new` 를 쓰면 자동으로 들어간다.

```md
---
title: '글 제목'
description: '한 줄 요약'
pubDate: 2026-11-04
updatedDate: 2026-11-05
tags: ['여행', '맛집']
draft: false
---

여기부터 본문.
```

| 항목 | 꼭 필요? | 설명 |
|---|:---:|---|
| `title` | ✔ | 글 제목 |
| `pubDate` | ✔ | 쓴 날짜. 글 목록은 이 날짜 최신순 |
| `description` | | 한 줄 요약. 검색 결과, 링크 미리보기, RSS에 나온다. 웬만하면 쓰자 |
| `updatedDate` | | 고친 날짜. 쓰면 글 위에 "수정 2026-11-05"로 나온다 |
| `tags` | | 태그 여러 개 |
| `draft` | | `true` 면 내 컴퓨터에서만 보임 |

### 글 주소 정하는 법

- **폴더 이름 = 카테고리, 파일 이름 = 글 주소**
- 파일 이름은 영어 소문자와 `-` 로 짓는 게 좋다 (`first-day.md`)
- **숫자만으로 짓지 말 것**. `2.md` 는 글 목록 2쪽 주소와 겹친다
- 한 번 올린 글의 파일 이름이나 폴더를 바꾸면 **주소가 바뀐다**. 이미 공유한 링크와 달린 댓글이 끊기니 조심

### 기본 문법

| 이렇게 쓰면 | 이렇게 나온다 |
|---|---|
| `## 제목` ~ `###### 제목` | 본문 제목 (`##` 가 가장 큼. `#` 하나는 글 제목용이라 안 씀) |
| `**굵게**`, `*기울임*`, `~~취소선~~` | **굵게**, *기울임*, ~~취소선~~ |
| `` `코드` `` | `코드` |
| `[글자](https://주소)` | 링크 |
| `> 인용` | 인용문 |
| `---` | 구분선 (윗줄과 사이에 빈 줄 필요) |
| `- [ ] 할 일`, `- [x] 한 일` | 체크리스트 |
| `<kbd>Ctrl</kbd>` | <kbd>Ctrl</kbd> 키 모양 |
| `<details><summary>제목</summary>내용</details>` | 접었다 펴는 상자 |
| 표 (`\| 칸 \| 칸 \|`) | 표 |

### 사진

```md
![사진 설명](./images/sea.jpg)
![사진 설명](./images/sea.jpg "사진 아래에 나올 캡션")
```

- 사진 파일은 글과 같은 카테고리 폴더 안에 둔다. 많아지면 `images` 폴더를 만들어 모으면 깔끔하다
- 경로는 `./` 로 시작한다
- `[사진 설명]` 은 사진이 안 뜰 때나 화면 읽기 프로그램이 읽어주는 글이다. 비워두지 말자
- 따옴표 안에 글을 쓰면 사진 아래에 **캡션**으로 나온다
- 용량 줄이기, 폰용 작은 사진 만들기는 자동이다. 원본은 가로 2000px 정도면 충분하다
- 방문자가 사진을 누르면 화면 가득 크게 볼 수 있다
- 움짤(GIF)도 똑같이 넣으면 된다

### 수식

```md
시간 복잡도는 $O(n \log n)$ 이다.

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

- 달러 하나로 감싸면 문장 안 수식, 두 개로 위아래를 감싸면 가운데 정렬 수식
- 문법은 LaTeX. 자주 쓰는 것: `\frac{a}{b}`, `x^2`, `a_i`, `\sqrt{x}`, `\le`, `\ge`, `\sum`, `\log`
- 오타가 있어도 사이트가 안 깨지고 그 수식만 빨갛게 보인다

## `/` 명령어로 빨리 쓰기

VS Code나 Cursor에서 마크다운 파일에 **`/명령어`** 를 치고 `Enter` 를 누르면 틀이 들어간다. `Tab` 으로 다음 칸, 목록이 안 뜨면 `Ctrl+Space`.

| 명령어 | 들어가는 것 |
|---|---|
| `/new` | 글 정보 (오늘 날짜 자동) |
| `/date` | 오늘 날짜 |
| `/heading` | 제목 |
| `/bold`, `/italic`, `/strike` | 굵게, 기울임, 취소선 |
| `/link`, `/img` | 링크, 사진 |
| `/quote`, `/divider`, `/toggle`, `/table` | 인용문, 구분선, 접는 상자, 표 |
| `/ul`, `/ol`, `/check` | 글머리표, 번호, 체크리스트 |
| `/code`, `/inline`, `/collapse`, `/diff`, `/term` | 코드 블록, 짧은 코드, 접힌 코드, 추가/삭제 표시 코드, 터미널 |
| `/math`, `/mathblock` | 수식 |
| `/kbd` | 키보드 키 |

> `/heading` 을 골랐는데 앞의 `/` 가 남으면, 편집기에 원래 들어 있는 비슷한 이름의 명령을 고른 것이다. 설명이 한국어로 된 것을 고르면 된다. 헷갈리면 편집기에서 `Ctrl+Shift+P` → **Snippets: Insert Snippet** 목록에서 영어 설명 기본 항목들(Insert heading, Insert bold text …)에 마우스를 올려 눈 모양 아이콘으로 숨겨두면 편하다.

## 카테고리와 태그

- **카테고리** = 큰 주제. `src/content/blog/` 아래 **폴더 하나**가 카테고리 하나다
  - 폴더를 만들고 글을 넣으면 홈 화면 앱 아이콘, 카테고리 목록, 글 목록이 자동으로 생긴다
  - 폴더 안에 폴더를 또 만들면 안 된다 (한 단계만)
  - 빈 폴더는 안 나온다. 글이 하나 이상 있어야 한다
- **태그** = 세부 키워드. 글 정보의 `tags` 에 여러 개 단다
  - 태그 목록 페이지, 태그별 글 목록이 자동으로 생긴다
  - 태그가 겹치는 글끼리 글 아래 **관련 글**로 추천되니, 꾸준히 같은 이름으로 달아두면 좋다
  - 대소문자만 다른 태그(`Travel`, `travel`)는 하나로 합쳐진다

## 홈 화면 꾸미기

### 카테고리 앱 아이콘

아무 설정을 안 해도 폴더 이름과 자동 색으로 아이콘이 만들어진다. 바꾸고 싶으면 `src/consts.ts` 의 `CATEGORY_APPS` 에 한 줄 추가한다.

```ts
export const CATEGORY_APPS = {
	diary: { label: 'Diary', icon: 'lucide:book-open', color: ['#ff9a8b', '#e0566a'] },
};
```

- 맨 앞(`diary`)은 **폴더 이름**
- `label`: 아이콘 아래 이름
- `icon`: 아이콘 이름. [Lucide 아이콘](https://icones.js.org/collection/lucide)에서 마음에 드는 걸 누르면 `lucide:...` 이름이 나오니 복사한다. 브랜드 로고는 [Simple Icons](https://icones.js.org/collection/simple-icons) (`simple-icons:...`)
- `color`: 배경 색 `[위쪽, 아래쪽]`. 아래쪽을 조금 어둡게 하면 흰 아이콘이 잘 보인다
- 아이콘 이름을 틀리면 미리보기가 에러로 멈춰서 바로 알 수 있다

### 바깥 링크 앱, 아래 독

`src/pages/index.astro` 위쪽에서 고친다.

- `links`: 카테고리 앱 뒤에 붙는 바깥 링크 (GitHub, Gmail 등). 인스타그램 같은 걸 추가해도 된다
- `dock`: 아래 독 메뉴 (Categories, Tags, Search, About)의 순서와 색

### 배경화면

1. 마음에 드는 사진을 `src/assets/wallpaper.jpg` 에 **같은 이름으로 덮어쓴다**
2. 끝. 크기 줄이기는 자동이다

사진 고르는 요령:

- 가로 2560×1600 정도가 좋다 (최소 1920×1080)
- 화면에 맞게 **가운데를 기준으로 잘린다**. 폰에서는 가운데 1/3만 보이니 중요한 게 가운데 있는 사진이 좋다
- 아이콘 이름이 흰 글씨라 **어두운 사진**이 잘 어울린다
- 선이나 무늬가 있는 사진이면 Chrome에서 독 유리 가장자리가 렌즈처럼 휘어 보이는 효과가 잘 산다

### 위젯

홈 화면의 **기록(잔디)**, **최근 글**, **랜덤 글** 위젯은 글만 쓰면 알아서 채워진다.

- 기록: 최근 20주 동안 글을 쓴 날이 색칠된다. 많이 쓴 날일수록 진하다
- 최근 글: 가장 최근 글
- 랜덤 글: 들어올 때마다 다른 글. 오른쪽 위 🔀 를 누르면 다시 고른다
- 사이트에 올릴 때 계산되므로, 한동안 글을 안 올리면 잔디도 그대로 멈춰 있다

## 사이트 색 바꾸기

전체 색은 `src/styles/global.css` 맨 위에서 바꾼다.

| 이름 | 쓰이는 곳 |
|---|---|
| `--bg` | 배경 |
| `--text` | 본문 글자 |
| `--muted` | 날짜, 메뉴 같은 흐린 글자 |
| `--accent` | 링크, 강조 (지금은 핑크) |
| `--accent-2` | 짧은 코드 글자, 메뉴 밑줄 (지금은 시안) |
| `--accent-3` | 카드에 마우스를 올렸을 때 테두리, 인용문 막대 (지금은 보라) |
| `--title-gradient` | 페이지 제목 그라데이션 |

코드 블록 색 테마는 `ec.config.mjs` 의 `themes` 에서 바꾼다 ([테마 목록](https://shiki.style/themes)). 테마를 바꾼 뒤 미리보기에서 코드가 깨져 보이면 [문제 해결](#문제-해결)을 본다.

## 댓글

[giscus](https://giscus.app)를 쓴다. 댓글은 내 GitHub 저장소의 **Discussions** 에 저장되고, 댓글을 달려면 방문자가 GitHub 로그인을 해야 한다.

설정 (처음 한 번):

1. 저장소 **Settings → General → Features** 에서 **Discussions** 를 켠다
2. [giscus 앱](https://github.com/apps/giscus)을 내 저장소에 설치한다
3. [giscus.app](https://giscus.app) 에서 저장소 이름을 넣고, Discussion 카테고리는 **Announcements** 를 고른다
4. 아래에 나오는 `data-repo`, `data-repo-id`, `data-category-id` 값을 `src/consts.ts` 의 `GISCUS` 에 넣는다

관리:

- 댓글 지우기, 숨기기, 잠그기는 GitHub 저장소 → **Discussions** 에서 한다
- 글 주소를 바꾸면 기존 댓글과 연결이 끊긴다. 옮기려면 그 Discussion 제목을 새 주소로 고친다
- 미리보기(`npm run dev`)에서는 댓글창 색이 기본 테마로 보인다. 실제 사이트에서는 블로그 색에 맞춰 나온다

## 방문 통계

[GoatCounter](https://www.goatcounter.com)를 쓴다. 무료이고 쿠키를 안 써서 동의 팝업이 필요 없다.

1. GoatCounter에 가입하면서 사이트 코드를 정한다 (예: `myblog` → 대시보드 `https://myblog.goatcounter.com`)
2. 그 코드를 `src/consts.ts` 의 `GOATCOUNTER_CODE` 에 넣는다
3. 대시보드에서 페이지별 조회수, 방문 경로, 기기, 국가를 볼 수 있다

- 내 컴퓨터 미리보기에서 본 건 안 잡힌다
- 통계를 안 쓰려면 `GOATCOUNTER_CODE` 를 `''` 로 비운다

## 검색엔진 등록

사이트맵, 검색엔진 안내 파일은 자동으로 만들어진다. **검색 결과에 빨리 뜨게 하려면 등록을 한 번 해준다.**

1. **Google**: [Search Console](https://search.google.com/search-console) → 속성 추가 → **URL 접두어** 에 내 블로그 주소 → 확인 방법 **HTML 태그** → `content="..."` 안의 값을 `src/consts.ts` 의 `SITE_VERIFICATION.google` 에 넣고 사이트에 올린다 → "확인" → 왼쪽 **Sitemaps** 에 `sitemap-index.xml` 제출
2. **네이버**: [서치어드바이저](https://searchadvisor.naver.com) → 사이트 등록 → **HTML 태그** 값을 `SITE_VERIFICATION.naver` 에 넣고 올린다 → "확인" → **요청 → 사이트맵 제출** 에 `내주소/sitemap-index.xml`

> 확인 값을 나중에 지우면 소유 확인이 풀리니 그대로 둔다. 등록 전이라면 두 값을 `''` 로 비워둔다.

## 방문자가 쓰는 기능

따로 설정할 것 없이 자동으로 붙는다. 알아두면 글 쓸 때 도움이 된다.

- **목차**: 본문의 `##`, `###` 제목으로 자동 생성. 넓은 화면에서는 오른쪽에 떠 있다
- **소제목 링크**: 제목에 마우스를 올리면 🔗 버튼이 나오고, 누르면 그 부분으로 바로 가는 링크가 복사된다
- **읽은 만큼 진행 바**: 화면 맨 위 얇은 줄이 읽은 만큼 차오른다
- **관련 글 / 이전·다음 글**: 글 맨 아래에 나온다
- **맨 위로 버튼**: 긴 글에서 오른쪽 아래에 나온다
- **검색**: 메뉴의 Search. 제목, 본문, 코드까지 찾는다 (사이트에 올려야 동작하고, 내 컴퓨터 미리보기에서는 안 된다)
- **RSS**: 메뉴의 RSS 주소를 RSS 리더에 넣으면 새 글 알림을 받을 수 있다
- **링크 미리보기**: 카톡, 디스코드 등에 링크를 보내면 제목과 한 줄 요약(`description`)이 뜬다
- **없는 주소**: 주소를 잘못 치면 "페이지를 찾을 수 없습니다"와 함께 주소가 비슷한 글을 추천해준다

## 문제 해결

### 새 글이 사이트에 안 보인다

- `draft: true` 로 되어 있지 않은지 확인
- push 하고 1~2분 기다린 뒤 `Ctrl+Shift+R`
- GitHub 저장소 → **Actions** 탭에서 맨 위 작업이 초록 체크인지 확인. 빨간 X면 눌러서 에러 메시지를 본다

### 에러 메시지가 뜬다

| 메시지에 이런 말이 있으면 | 원인 |
|---|---|
| `title` … `Required`, `pubDate` … `Expected type date` | 글 정보가 빠졌거나 `---` 줄이 잘못됨 (`-` 세 개인지 확인) |
| `카테고리 폴더는 한 단계만 허용됨` | 폴더 안에 폴더를 만듦 |
| `Unable to locate "..." icon!` | 아이콘 이름 오타 |

### 미리보기에서 코드 블록이 깨져 보인다

코드 블록 테마를 바꾼 뒤에 생긴다.

1. 미리보기(`npm run dev`)를 끈다 (터미널에서 `Ctrl+C`)
2. `npm run clean`
3. 다시 `npm run dev`

### 미리보기에서 draft 글의 사진이 안 보인다

미리보기를 켜둔 채로 다른 터미널에서 `npm run build` 나 `npm run check` 를 돌리면 생긴다. 그 글 파일을 한 번 저장하면 다시 보인다.

### 홈 화면 애니메이션이 안 나온다

컴퓨터의 "애니메이션 줄이기" 설정이 켜져 있는 것이다. Windows는 설정 → 접근성 → 시각 효과 → **애니메이션 효과** 를 켠다. 폰에서 화면 가장자리를 밀어서 뒤로 가는 경우는 브라우저 자체 애니메이션이 나오는 게 정상이다.

### Gmail 앱을 눌러도 반응이 없다

컴퓨터에 메일 앱이 설정되어 있지 않은 것이다. 크롬에서 Gmail을 기본 메일 앱으로 설정하면 Gmail 웹이 열린다.

## 자주 쓰는 명령어

터미널에서 블로그 폴더를 연 상태로 입력한다.

| 명령어 | 하는 일 |
|---|---|
| `npm install` | 처음 한 번 준비 |
| `npm run dev` | 내 컴퓨터에서 미리 보기 (`http://localhost:4321`). 끌 때는 `Ctrl+C` |
| `npm run build` 후 `npm run preview` | 실제 사이트와 똑같이 만들어서 보기 (검색 기능 확인용) |
| `git add .` → `git commit -m "메모"` → `git push` | 사이트에 올리기 |
